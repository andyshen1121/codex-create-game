# 网页版坦克大战设计说明

## 目标
实现单人闯关 + 本地双人同屏的经典坦克大战，使用原生 HTML + Canvas + JS，画布尺寸 800x600。关卡为预设地图，三类敌人（基础/快速/重甲），基地被毁或玩家全灭则失败。

## 架构与模块
- Game：状态机（开始/进行/通关/失败）、主循环、调度
- Map：关卡网格、静态障碍与可破坏方块
- Tank/Bullet/Enemy：实体生命周期（update/draw）
- Input：双人键位映射与边缘触发
- Collision：AABB 碰撞与回退
- Spawner：敌人生成节奏与总数
- HUD：生命、剩余敌人、关卡信息

## 数据流
初始化读取二维数组关卡，生成障碍层与装饰层；每帧读取输入生成玩家意图，更新实体并处理碰撞与销毁；Spawner 按间隔生成敌人；Game 判定通关/失败。

## 规则
- 每名玩家 3 条命，敌人清空通关
- 基地被毁直接失败
- 砖墙可被摧毁，钢墙不可摧毁，水阻挡坦克，草仅视觉遮挡

## 错误处理
- 输入互斥与防抖（相反方向按下取最后）
- 生成点被占用则延迟生成
- 资源失败时降级为纯色方块渲染

## 测试策略（轻量）
- 手工：移动、射击、碰撞、基地失败、敌人生成与通关
- 自动：AABB 碰撞、子弹击砖墙销毁、生成计数与通关条件
